
**Cavia** é um protótipo de aplicativo voltado ao acompanhamento da saúde e do bem-estar de porquinhos-da-índia (*Cavia porcellus*). O projeto busca auxiliar tutores no monitoramento da rotina dos animais, reunindo informações e recursos relacionados aos seus cuidados em um único ambiente digital.

## Sobre o projeto

O aplicativo foi desenvolvido como parte de um Trabalho de Conclusão de Curso em Design, com o objetivo de explorar como o design de interfaces pode contribuir para o acompanhamento dos cuidados com porquinhos-da-índia.

A proposta considera as particularidades da espécie e busca oferecer uma experiência simples e acessível para o registro e a consulta de informações sobre os animais.

## Funcionalidades

O protótipo reúne recursos relacionados ao acompanhamento dos animais, como:

- Cadastro e visualização dos animais;
- Registro de informações sobre a rotina;
- Acompanhamento de dados de saúde;
- Histórico de registros;
- Visualização de informações e indicadores;
- Alertas relacionados a possíveis alterações nos dados monitorados.

## Tecnologias utilizadas

- **Quarto:** utilizado na estruturação e geração das páginas HTML a partir de arquivos Markdown (`.qmd`);
- **HTML:** estruturação das páginas;
- **CSS:** estilização das interfaces;
- **JavaScript:** implementação dos comportamentos e funcionalidades da aplicação;
- **Claude:** ferramenta de inteligência artificial utilizada no processo de geração do código.

## Visualização do projeto

Para visualizar o projeto localmente, é necessário ter o [Quarto](https://quarto.org/docs/get-started/) instalado.

Após clonar o repositório, abra o terminal na pasta do projeto e execute:

```bash
quarto preview
```

O comando inicia uma pré-visualização local do site no navegador.

## Observações

Este projeto corresponde a um protótipo desenvolvido para fins acadêmicos.
